# Collections refinement prompt

Tool: built-in Image Generation. Output: `collections-refinement.png`. Reference inputs: the first displayed collection-cover gallery and the second displayed horizontal-shelf concept from the initial design set. The user likes both and finds the third too spread out.

Use case: ui-mockup. Create one production-quality desktop Collections screen for Walls, combining the first reference's compact header/actions, restrained green accent and comfortable density with the second reference's multiple-image previews per collection. Target 1440 × 1024, natural proportions, app content only.

Use a slim top navigation with Walls, Collections selected, All wallpapers, and Settings. Put Your collections on the same horizontal line as the Add wallpapers primary button and quiet New collection action. Beneath it show Aviation and Landscapes, shuffled every hour, with Edit. Keep the header compact.

Create three collection shelves: Aviation, Landscapes, Abstract. Put each collection name and Open link immediately above its three full-width image previews, with a separate Use for wallpapers checkbox on the right of that same line. Aviation and Landscapes are checked. Abstract is unchecked. Remove the empty left-hand label columns from the second reference. Keep consistent gutters, modest inter-shelf spacing, subtle dividers, and no boxed card bodies. Fit all rows and a Sample collection imagery footer without clipping.

Aviation imagery: glider above pale clouds, silver aircraft wing in a peach sky, small aircraft over blue coastal water. Landscapes: misty green alpine valley, black-sand coast, layered mountains at dawn. Abstract: cream paper folds, limestone curves, soft geometric shadows. Preserve the atmospheric photography of the references.

Light warm-neutral surface, graphite text, muted forest-green accent, contemporary system-like sans-serif, 14–16 px body type, modest headings, approximately 6 px image radii, no drop shadows. Compact and comfortable, not cramped. No sidebar, oversized feature image, OS/browser frame, perspective, schedule timeline, queue, metrics, storage meters, AI/discovery/admin navigation, ads, invented statistics, or extra features. Only the small Edit entry point leads to folders/order/frequency controls off-screen.

This records the generation direction in a reusable form; visual typography and dimensions still require implementation verification. The image is a concept, not a working app screenshot.
